## ২. বাংলাদেশি মার্কেটের বাস্তবতা (ডিজাইন ও ফিচারে যা প্রভাব ফেলে)

1. **মোবাইল-ফার্স্ট** — ৮৫-৯০% ট্রাফিক মোবাইল, বেশিরভাগ মিড/লো-রেঞ্জ অ্যান্ড্রয়েড। অ্যানিমেশন হালকা রাখতে হবে, `prefers-reduced-motion` মানতে হবে।
2. **ফেসবুক থেকে ট্রাফিক** — বেশিরভাগ সেল আসে FB/IG অ্যাড থেকে। তাই **Meta Pixel + Conversions API (সার্ভার-সাইড)** বাধ্যতামূলক, আর **সিঙ্গেল-প্রোডাক্ট ল্যান্ডিং পেজ** খুব জরুরি।
3. **ক্যাশ অন ডেলিভারি (COD) প্রধান** — ৬০-৮০% অর্ডার COD। তাই:
   - **ফ্রড চেক**: কাস্টমারের ফোন নম্বর দিয়ে কুরিয়ার ডেলিভারি সাকসেস রেট দেখা।
   - **ডেলিভারি চার্জ অগ্রিম** bKash-এ নেওয়ার অপশন।
   - **অর্ডার কনফার্মেশন কল/SMS** ফ্লো।
4. **গেস্ট চেকআউট + ফোন নম্বর** — ইমেইল নয়, **ফোন + OTP** হলো আইডেন্টিটি। অ্যাকাউন্ট বানানো বাধ্যতামূলক নয়।
5. **ইনকমপ্লিট/অ্যাবান্ডনড অর্ডার** — চেকআউটে নাম+ফোন লিখে চলে গেলে সেটা সেভ হবে; টিম কল দিয়ে অর্ডার কনভার্ট করবে (BD-তে খুব কার্যকর)।
6. **ঠিকানা** — বিভাগ → জেলা → উপজেলা/থানা ড্রপডাউন; ঢাকার ভেতরে/বাইরে ডেলিভারি চার্জ আলাদা।
7. **ভাষা** — বাংলা ডিফল্ট + ইংরেজি টগল। দাম ৳ চিহ্নে, বাংলা সংখ্যা অপশনাল।
8. **পেমেন্ট** — COD, bKash, Nagad, Rocket, কার্ড (SSLCommerz / aamarPay / ShurjoPay দিয়ে)।
9. **কুরিয়ার** — Steadfast, Pathao, RedX, Paperfly, eCourier — API দিয়ে এক ক্লিকে বুকিং ও ট্র্যাকিং।
10. **SMS** — অর্ডার কনফার্ম, শিপড, ডেলিভারড SMS (BulkSMSBD / SSL Wireless / Alpha SMS ইত্যাদি)।
11. **WhatsApp/Messenger** — ফ্লোটিং চ্যাট বাটন, "WhatsApp-এ অর্ডার করুন"।
12. **উৎসব-ভিত্তিক সেল** — রমজান, ঈদুল ফিতর, ঈদুল আযহা, শবে বরাত — ক্যাম্পেইন/ব্যানার/কাউন্টডাউন ড্যাশবোর্ড থেকে সেট করা যাবে।

## ৩. প্রোডাক্ট ও কনটেন্ট রিসার্চ (ইসলামিক লাইফস্টাইল)

### সম্ভাব্য ক্যাটাগরি ট্রি
- **পুরুষ**: পাঞ্জাবি, কাবলি সেট, জুব্বা/থোব, টুপি, পায়জামা
- **নারী**: বোরকা/আবায়া, হিজাব, নিকাব, খিমার, হাতমোজা/পা-মোজা
- **আতর ও সুগন্ধি**: অ্যালকোহল-মুক্ত আতর, উদ, বাখুর
- **ইবাদত সামগ্রী**: জায়নামাজ, তাসবিহ, কুরআন শরীফ, রেহাল, মিসওয়াক
- **বই**: তাফসির, হাদিস, সীরাত, শিশুদের ইসলামিক বই
- **খাদ্য/সুন্নাহ ফুড**: খেজুর, মধু, কালোজিরা, জমজম, যয়তুন তেল
- **হোম ডেকর**: ক্যালিগ্রাফি ফ্রেম, ওয়াল আর্ট
- **গিফট বক্স**: ঈদ/বিয়ে/হজ্জ গিফট কম্বো
- **শিশু**: বাচ্চাদের পাঞ্জাবি, হিজাব, শেখার খেলনা

### প্রোডাক্টের ধরন (ডাটা মডেলে সাপোর্ট লাগবে)
- **ভ্যারিয়েবল প্রোডাক্ট**: সাইজ × রং (পাঞ্জাবি, বোরকা) — প্রতিটা ভ্যারিয়েন্টের আলাদা SKU, স্টক, দাম, ছবি
- **সিম্পল প্রোডাক্ট**: আতর (ml অনুযায়ী ভ্যারিয়েন্ট হতে পারে), বই
- **কম্বো/বান্ডেল**: গিফট বক্স (একাধিক প্রোডাক্ট মিলে, স্টক অটো কমবে)
- **প্রি-অর্ডার**: নতুন কালেকশন/আমদানি পণ্য
- **ডিজিটাল** (ভবিষ্যতে): ই-বুক

### প্রোডাক্ট পেজে কী থাকবে
গ্যালারি (জুম, ভিডিও), দাম + ছাড়, ভ্যারিয়েন্ট সিলেক্টর (রং সোয়াচ), **সাইজ চার্ট**, স্টক স্ট্যাটাস, "এখনই কিনুন" + "কার্টে যোগ করুন", ডেলিভারি সময়/চার্জ, ফ্যাব্রিক/উপাদান, রিভিউ (ছবিসহ), প্রশ্ন-উত্তর, ফ্রিকোয়েন্টলি বট টুগেদার, রিলেটেড প্রোডাক্ট, রিসেন্টলি ভিউড, WhatsApp-এ জিজ্ঞাসা, শেয়ার বাটন।

## ৬. অ্যাডমিন ড্যাশবোর্ড (Filament) — মডিউল তালিকা

মেনু গ্রুপ অনুযায়ী সাজানো থাকবে, যাতে অর্গানাইজড ও সহজ হয়:

### 📊 ড্যাশবোর্ড
- আজকের/সপ্তাহের/মাসের সেল, অর্ডার সংখ্যা, AOV, কনভার্শন
- স্ট্যাটাস অনুযায়ী অর্ডার কাউন্ট, লো-স্টক অ্যালার্ট, টপ প্রোডাক্ট, রিটার্ন রেট
- কুরিয়ার অনুযায়ী ডেলিভারি সাকসেস রেট

### 🛒 অর্ডার
- অর্ডার লিস্ট (ফিল্টার: স্ট্যাটাস, পেমেন্ট, কুরিয়ার, তারিখ, সোর্স/UTM)
- স্ট্যাটাস ফ্লো: `Pending → Confirmed → Processing → Shipped → Delivered` / `Cancelled` / `Returned` / `On Hold`
- **ফ্রড চেক** বাটন (ফোন নম্বরের কুরিয়ার হিস্ট্রি)
- **এক ক্লিকে / বাল্ক কুরিয়ার বুকিং** (Steadfast, Pathao, RedX)
- ইনভয়েস / শিপিং লেবেল প্রিন্ট (বাল্ক)
- ম্যানুয়াল অর্ডার তৈরি (ফোনে আসা অর্ডার)
- **ইনকমপ্লিট অর্ডার** লিস্ট → এক ক্লিকে অর্ডারে কনভার্ট
- অর্ডার নোট, টাইমলাইন/অ্যাক্টিভিটি লগ, কে কোন পরিবর্তন করল
- রিটার্ন/এক্সচেঞ্জ/রিফান্ড
- ব্লক লিস্ট (ফেক অর্ডারকারী ফোন/IP/ডিভাইস)
- **Fraud Guard সেটিংস পেজ** — ফেক নম্বর ডিটেকশন, IP/ফোন কুলডাউন, অটো-ব্লক অন ক্যানসেল, সাকসেস রেট থ্রেশহোল্ড (বিস্তারিত: সেকশন ১১.১)
- **পেমেন্ট ভেরিফিকেশন** — bKash/Nagad সেন্ড-মানির TrxID Verify/Reject
- নতুন অর্ডারে **Telegram / SMS অ্যালার্ট** স্টাফকে

### 📦 ক্যাটালগ
